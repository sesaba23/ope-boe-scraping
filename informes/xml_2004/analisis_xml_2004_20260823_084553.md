## Ventajas del XML

Metadatos explícitos, jerarquía validable y bloques de texto delimitados.

## Limitaciones del XML

Los campos de convocatoria pueden seguir dentro de texto libre o tablas que requieren interpretación.

## Recomendación arquitectónica

Priorizar un enfoque híbrido: XML para metadatos y delimitación; análisis textual para los campos funcionales.
