# Instrucciones para Codex

Este es un proyecto Python existente y funcional.

## Reglas

- No modificar funcionalidades existentes salvo petición expresa.
- Realizar cambios mínimos y localizados.
- Antes de modificar código, identificar los archivos afectados.
- No añadir dependencias nuevas sin justificarlo.
- Utilizar el entorno virtual `.venv`.
- Mantener actualizado `requirements.txt` cuando corresponda.
- Ejecutar las pruebas disponibles después de modificar código.
- No eliminar código funcional sin autorización.
- Explicar los cambios realizados.
